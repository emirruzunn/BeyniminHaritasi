# 🌐 Beynimin Haritası

Frutiger Aero ve Neo-Y2K estetiğiyle tasarlanmış interaktif zihin/portfolyo haritası.

## 🚀 Canlı Demo
[Projeyi Canlı İncele](https://emirruzunn.github.io/BeyniminHaritasi/)

## ✨ Özellikler
- Cam (glassmorphism) ve parlama efektleri
- İnteraktif gezinilebilir düğüm/harita yapısı
- Mobil ve masaüstü uyumlu responsive tasarım

## 🛠️ Kullanılan Teknolojiler
- HTML5 / Vanilla CSS3 / JavaScript (ES6+)
